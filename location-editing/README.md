# Редактирование улицы в Blender

[Скачать street-template.blend](https://github.com/syxelll/bomzh_game/raw/refs/heads/main/location-editing/street-template.blend)

Файл создан в Blender 5.2.3 из реальных мешей текущей процедурной улицы (`src/world.js`). Это редактируемая копия окружения, а не автоматическая связь Blender с игрой. Дорога, дома, окна, фонари, лавочки, урны и бутылки сохранены отдельными объектами. Текстуры кирпича, асфальта с трещинами, бетона, ржавчины и надписей перенесены из текущей игры вместе с UV и упакованы внутрь `.blend`: отдельные файлы изображений скачивать не нужно. Персонажей, анимаций и игровой логики в файле нет.

## Что редактировать

- `EDIT_26m_MAIN`: основная секция, X от 0 до 26 метров. Здесь меняй дома, дорогу, реквизит и материалы.
- `REFERENCE_NEIGHBOR_-1`, `REFERENCE_NEIGHBOR_1`: соседние секции для проверки стыков. Выделение заблокировано; коллекции можно скрыть в Outliner.
- `GUIDES_DO_NOT_EXPORT`: границы секции, зона движения, начало следующей секции и габарит персонажа высотой 1,85 м. Это только ориентиры.
- `PREVIEW_CAMERA_AND_LIGHTS`: пример камеры игры и свет. Камера в самой игре движется и меняет приближение, поэтому проверять надо и широкий кадр, и крупный, и вертикальный экран.

1 единица = 1 метр. В Blender: X — вдоль улицы, Z — вверх, Y — глубина. Перевод в игру: game X = Blender X, game Y = Blender Z, game Z = -Blender Y. Земля около Z=0; игровая полоса по Blender Y от -2.1 до 2.0. Передний край дороги расположен в отрицательной стороне Y, дома — в положительной. Объекты стоят в игровых мировых координатах, их Origins перенесены в центр каждой детали для удобного перемещения. Основная секция содержит 426 мешей; детали сгруппированы в Buildings_and_details, Road_and_sidewalks, Street_props и Pickup_references.

## Рекомендуемый порядок

1. Сохрани копию как `street_01.blend`. Оставь масштаб и положение секции X=0..26.
2. Сначала расставь крупные формы: дома, дорогу, тротуар. Проверь кадр через Numpad 0 и силуэт героя по габаритному ориентиру.
3. Оставь полосу движения свободной. Сейчас столкновения с декорациями не вычисляются: поставленная поперёк дороги урна или стена сама по себе не станет препятствием. Для препятствий потребуется отдельно добавить коллизии в игру.
4. По краям X=0 и X=26 сохрани одинаковые высоту, ширину и материал дороги/тротуара. Не ставь на стыках поперечные стены: уровни бесконечные, секции должны соединяться.
5. Добавь детали и материалы. Для первого варианта достаточно простых Principled BSDF материалов с Base Color/Roughness. Процедурные шейдеры Blender нужно будет запечь перед GLB; внешние текстуры упакуй через File → External Data → Pack Resources.
6. Бутылки — ориентиры текущего размещения; подбор предметов генерируется кодом. Новые позиции бутылок, появления врагов и интерактивных объектов согласуем отдельно, не встраивай их как обычные декоративные меши для финального экспорта.
7. Пришли `.blend` через Drive. Достаточно исходного файла: я подготовлю экспорт и подключение. Для самостоятельного экспорта выдели только окружение основной секции, File → Export → glTF 2.0 → GLB → Selected Objects. Не включай соседние секции, ориентиры, свет и камеру. Надписи сейчас являются текстурой на плоскости.

Лучше сначала сделать одну готовую секцию и проверить её в игре, затем 3–5 вариантов с теми же стыками. Они смогут чередоваться при бесконечном прохождении. Пока файл не подключён вместо процедурной улицы — внешний вид игры этим коммитом не меняется.

## Повторное создание шаблона

После `npm install`:

```sh
node scripts/export-street.mjs
blender -b --factory-startup --python scripts/blender/export_street_template.py
```

Node-экспортёр сам запускает временный Vite-сервер и Chromium (по умолчанию `/usr/bin/chromium`, переопределяется `CHROMIUM_PATH`), чтобы получить настоящие canvas-текстуры. Вершины с учётом всех InstancedMesh, UV, материалы и PNG передаются через `/tmp/street-meshes.json`. Пути можно переопределить: аргументом Node-скрипта и параметрами Blender-скрипта `-- --input PATH --output PATH`.

Освещение Blender является ориентиром: Three.js и Blender рендерят свет по-разному. Окончательный свет настраивай в [редакторе игры](https://syxelll.github.io/bomzh_game/?editor=lighting). Предпросмотр в Blender рассчитан на Cycles. Коллекции ориентиров скрыты от рендера, соседние секции заблокированы только от выделения — в рендере они видны.
